# 首尾相乘・拆項分組

國中數學因式分解互動 APP：首項係數不為 1 的二次三項式（例：6x² + 7x − 3）。

**線上使用：** https://ryansu2021.github.io/cross-split-factoring/

## 學習流程（逐步揭露，答對才出現下一步）
1. 首尾相乘：6 × (−3) = −18
2. 找兩數：相乘 −18、相加 +7 → 9 和 −2
3. 拆中間項：6x² + 9x − 2x − 3
4. 分組提公因式：3x(2x + 3) − (2x + 3)
5. 提出共同括號：(2x + 3)(3x − 1)
6. 乘開檢查
7. 回頭看：連結十字交乘法

|---|---|
